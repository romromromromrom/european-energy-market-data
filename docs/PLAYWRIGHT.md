# Playwright

La capture réseau est un outil de découverte/fallback, pas le chemin quotidien pour EEX ou Nord Pool. `discover-network` écoute uniquement fetch/XHR, filtre les trackers courants, conserve les réponses JSON et produit URL, méthode, statut, MIME, taille, query parameters et clés JSON.

Le mode `--browser-profile` réutilise un profil légitime sans copier cookies ou credentials dans les archives. Aucun CAPTCHA, paywall ou contrôle d'accès ne doit être contourné.
